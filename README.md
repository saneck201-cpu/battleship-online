# Морской бой на 9 человек

Онлайн, у каждого свой экран. Сервер не нужен — работает на GitHub Pages (WebRTC через PeerJS).

## Как выложить
1. Создай репозиторий на GitHub (Public).
2. Add file → Upload files → закинь `index.html` и `README.md` → Commit.
3. Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save.
4. Через минуту сайт будет на `https://<твой-ник>.github.io/<репо>/`.

## Как играть
- Один создаёт комнату (он «хост» — его вкладка должна оставаться открытой), остальные заходят по ссылке или коду.
- Все расставляют корабли на общем поле 15×15 (другие не видят), потом ходят по очереди.
- Попал — ходишь ещё раз (можно отключить в лобби). Потопили все твои корабли — выбываешь. Последний выживший побеждает.

## Нюансы
- Если хост закроет вкладку или обновит страницу — игра закончится.
- Через очень строгие сети (некоторые мобильные операторы/корп. Wi-Fi) P2P может не соединиться — тогда попробуйте другой Wi-Fi.
